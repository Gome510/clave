# Clave

Editor local de estructura para archivos JSON de traducción. No requiere servidor: abre `index.html` en un navegador moderno.

## Flujo rápido

1. Importa el JSON maestro.
2. Mueve las claves al objeto de destino mediante arrastre, o selecciónalas, córtalas y pégalas en un objeto.
3. Renombra, busca/reemplaza o convierte el formato de las claves. Los valores no se modifican.
4. Importa uno o más archivos de traducción y descarga el resultado de cada uno.

Las claves nuevas se exportan con `""`. Las eliminadas ya no aparecen. Las movidas o renombradas conservan el texto de cada traducción.
